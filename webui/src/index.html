About this control plane
A dependency-free, reproducible WebUI for the dnscrypt-proxy-root Android module.

          
Security boundary
The WebUI requests allowlisted actions. The root shell remains responsible for validation, locking, ownership checks, and rollback.
Licensing
Project code is MIT-licensed. Bundled third-party notices and license texts ship in the module ZIP.

          
Device evidence
Desktop shell tests do not substitute for the published physical-device acceptance matrix. Consult REAL_DEVICE_ACCEPTANCE.md before production rollout.
